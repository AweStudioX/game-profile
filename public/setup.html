SELF-HOSTED PROFILE

配置档案.

无需改代码。真实记录只对通过验证的访客可见。

在 Vercel 连接 Steam

  1. 在 Vercel 导入项目中选择你的 fork。不配置任何值即可运行演示。
  2. 在项目 Settings → Environment Variables 中添加以下三个值（建议只添加到 Production）：
    STEAM_ID
    你的 17 位 SteamID64。Steam 账号详情可查看。
    STEAM_WEB_API_KEY
    从 Steam 官方页面申请。保存为 Secret，不要发给他人。
    PROFILE_PASSWORD
    用密码管理器生成 12–120 位不含空格的可打印 ASCII 密码，推荐至少 16 位。常见符号可以使用。保存为 Secret，不要复用 Steam 密码。
  3. 重新部署，并检查 Steam 隐私设置中的「游戏详情」对 API 可见。打开部署站点，点「登录查看」，用户名为 owner。

此页面不会接收 API Key。真实模式只连接 Steam；PlayStation 和 Nintendo 数据仅在演示模式中出现。

数据与隐私

配置的 SteamID 用于请求该账号的游戏库、活动和成就。数据临时保存在 Vercel 函数内存，不写入数据库；处理位置取决于部署者选择的函数区域。封面和成就图标由 Steam CDN 提供。本站与 Valve 无隶属关系，数据按原样提供，不保证完整或持续可用。
